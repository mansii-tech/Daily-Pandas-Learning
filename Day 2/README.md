
# Pandas Data Inspection, Filtering and Sorting

## Overview
This project covers basic Pandas operations using a student dataset.

## Topics Covered
- Creating a DataFrame
- Displaying data using `print()`
- Inspecting rows using `head()` and `tail()`
- Checking rows and columns using `shape`
- Displaying column names using `columns`
- Checking data types using `dtypes`
- Selecting single and multiple columns
- Filtering data using conditions
- Combining conditions using `&`
- Sorting data using `sort_values()`
- Sorting in ascending and descending order

## Learning Outcome
Learned how to inspect, select, filter, and sort student data using Python Pandas.
