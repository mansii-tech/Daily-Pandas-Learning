# Pandas DataFrame Basic Operations

## Introduction
This project covers the basic operations of a Pandas DataFrame using Python. It helps in understanding how to display, inspect, and filter data from a dataset.

## Objectives
- To understand the basics of Pandas DataFrame.
- To display the first and last rows of a dataset.
- To check the shape, column names, and data types.
- To select a specific column.
- To filter records based on a condition.

## Technologies Used
- Python
- Pandas Library

## Topics Covered

| Function | Description |
|---|---|
| `head()` | Displays the first 5 rows |
| `tail()` | Displays the last 5 rows |
| `shape` | Returns the number of rows and columns |
| `columns` | Displays all column names |
| `dtypes` | Shows the data type of each column |
| `df["Name"]` | Selects the Name column |
| `df[df["Marks"] > 80]` | Filters students who scored more than 80 marks |

## Sample Dataset
The dataset contains three columns:
- **Name:** Student name
- **Marks:** Marks obtained by the student
- **Age:** Age of the student


## Learning Outcome
Through this project, I learned how to inspect a DataFrame, access specific columns, understand data types, and filter data using Pandas.
